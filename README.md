# livresgourmands.net

## Description du projet

livresgourmands.net est une plateforme de commerce électronique spécialisée dans la vente de livres de cuisine, adaptée à différents niveaux : débutants, amateurs et chefs.

La plateforme permet notamment de rechercher et consulter des ouvrages, gérer un panier, effectuer des commandes, créer des listes de cadeaux, publier des avis et commentaires et effectuer des paiements en ligne sécurisés.

## Objectifs de l'étape 01

Cette première étape consiste à analyser les besoins du système et à réaliser sa modélisation initiale.

Les principaux objectifs sont :
- mettre en place le dépôt GitHub du projet ;
- réaliser le diagramme de cas d'utilisation ;
- réaliser une première ébauche du diagramme de classes ;
- identifier les principales règles de gestion du système.
